# Lesson 20 - Find Minimum in Rotated Sorted Array

## Core Idea

A rotated sorted array is not completely sorted, but its structure allows us to eliminate half of the search space.

Instead of searching for a target, we compare the middle element with the rightmost element to determine where the minimum can exist.

---

## Key Comparison

```python
numbers[mid] > numbers[right]

If true, the minimum must be to the right of mid.
left = mid + 1
mid is excluded because it is greater than numbers[right], so it cannot be the minimum.
numbers[mid] < numbers[right]
If true, the minimum is either at mid or somewhere to the left.
right = mid
We include mid because it could itself be the minimum.

Algorithm
def find_min(numbers):
    left = 0
    right = len(numbers) - 1

    while left < right:
        mid = (left + right) // 2

        if numbers[mid] > numbers[right]:
            left = mid + 1
        else:
            right = mid

    return numbers[left]

Why while left < right?
The goal is to shrink the search space until only one candidate remains.
When:
left == right
that remaining element is guaranteed to be the minimum.
Therefore:
while left < right:
is used instead of:
while left <= right:

Important Rules
- Compare numbers[mid] with numbers[right].
- If numbers[mid] > numbers[right], search right.
- If numbers[mid] < numbers[right], search left including mid.
- Use left < right.
- Return numbers[left] when the loop ends.

Complexity
- Time Complexity: O(log n)
- Space Complexity: O(1)
